Self-host

Your data stays on your machine.

RunIQ is self-hosted. Run it locally or on your own server in a few minutes.

1
Clone the repository

Grab the source from GitHub.

2
Add your settings

Copy the example environment file and add your keys, such as the language-model key for the coach.

3
Start it up

One command starts the app, then open it in your browser and import your runs.

Requires: DockerLLM API key (for the coach)
terminal
# 1. clone
$ git clone https://github.com/nct1673/runIQ.git
$ cd runiq

# 2. configure
$ cp .env.example .env

# 3. run
$ docker compose up -d
✔ RunIQ is running at http://localhost:3000
