RunIQ Tech Stack

A running-intelligence platform: sync Garmin data, analyse it, and talk to an AI coach about it.

How it fits together

Browser
Next.js + React→ API
FastAPI→ Database
PostgreSQL + pgvector
Garmin Connect→ ingestion → pandas / SQLAlchemy→ analytics, ML, coach (RAG)

Frontend

Framework

  • Next.js 15 App Router, server + client components
  • React 19 UI library
  • TypeScript 5 Type-checked code

Styling

  • Tailwind CSS 4 Utility classes, dark theme tokens
  • PostCSS CSS build pipeline

Notes

  • No chart/UI library Charts and components are hand-built
  • Node 20 Runtime in the Docker image

Backend

API

  • Python 3.11
  • FastAPI + Uvicorn REST API server
  • Pydantic v2 Validation and settings
  • httpx Outgoing HTTP calls
  • bcrypt Password hashing

Data & ingestion

  • garminconnect Pulls activities and records from Garmin
  • pandas, NumPy, SciPy Cleaning and calculations
  • Pandera DataFrame validation

Database

  • PostgreSQL 16 Main data store
  • pgvector Vector search for the coach's knowledge base
  • SQLAlchemy 2 ORM
  • Alembic Schema migrations
  • psycopg2 Postgres driver

AI & machine learning

AI Coach (RAG)

  • Ollama default Local chat model (qwen3:14b) with tool calling
  • Google Gemini optional Via LangChain (langchain-google-genai)
  • nomic-embed-text 768-dim embeddings via Ollama
  • Markdown knowledge base Training, recovery, heat, biomechanics notes
  • sqlglot Validates read-only SQL the coach may run

Modelling

  • scikit-learn, XGBoost, LightGBM Predictive models
  • SHAP Explaining model output
  • MLflow Experiment tracking

Video form analysis

  • MediaPipe 0.10.14 Pose estimation
  • OpenCV (headless) Video frame handling

External services

Data sources

  • Garmin Connect Activities, personal records
  • OpenWeather Hourly weather for each run

Tooling & deployment

Run & build

  • Docker Compose Three containers: frontend, backend, postgres
  • Conda (conda-forge) Local Python environment

Quality

  • pytest Backend tests
  • Ruff Python lint
  • TypeScript Frontend type checks
Read from frontend/package.json, backend/requirements.txt, backend/environment.yml, docker-compose.yml and backend/app/core/config.py.
